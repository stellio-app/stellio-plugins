# Split by color

<p align="center"><img src="logo.png" width="96" alt=""></p>

<details open>
<summary><b>English</b></summary>

3D print tool for Stellio. Opens from the **Plugins** menu in the left bar.

Splits a multicolor 3MF (Bambu Studio / OrcaSlicer) into a new 3MF with **one plate per color**.

- Pick the 3MF from your Stellio library, choose where to save the result and its name
- Color grouping with an adjustable tolerance; bed size taken into account
- Preview (analysis) before writing anything; the original file is never modified
- Needs the `ui`, `api:read` and `api:write` permissions (writes only the new 3MF), no network

Signed plugin with built-in code: it installs only if its signature is valid and Stellio trusts the key (Stellio 1.2.0 or later).

Install: Plugins › Catalogue › Split by color › Install, then enable it.

License: GNU AGPL v3.

</details>

<summary><b>日本語</b></summary>

Stellio 用の 3D プリントツールです。左バーの **Plugins** メニューから開きます。

マルチカラー 3MF（Bambu Studio / OrcaSlicer）を、**色ごとに 1 プレート**の新しい 3MF に分割します。

- Stellio のライブラリから 3MF を選び、保存先と結果の名前を指定
- 色のグループ化（許容値を調整可能）、ベッドサイズを考慮
- 書き込み前に解析（プレビュー）。元のファイルは変更されません
- `ui`、`api:read`、`api:write` の権限が必要（新しい 3MF のみ書き込み）、ネットワーク不使用

コード内蔵の署名付きプラグイン：署名が有効で Stellio がその鍵を信頼している場合のみインストールされます（Stellio 1.2.0 以降）。

インストール：Plugins › カタログ › Split by color › インストール、その後有効化。

ライセンス：GNU AGPL v3。
